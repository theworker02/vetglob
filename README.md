# vetglob

Vet and reshape glob text streams with deterministic transforms.

**Site:** https://theworker02.github.io/vetglob/

## Install / run

```bash
git clone https://github.com/theworker02/vetglob.git
cd vetglob
node src/cli.js
node --test
```
